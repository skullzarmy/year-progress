# Year Progress

A beautiful, stylized web application that visualizes the current year's progress in real-time.

Features multiple dynamic themes including Glassmorphism, Vaporwave, 80s Digital, Cyberpunk, and Terminal aesthetics, complete with unique CSS animations and seamless theme transitions.

## Features

- **Real-time Progress Calculation**: Down to the microsecond accuracy.
- **5 Distinct Themes**:
  - `glassmorphism`: Frosty, fluid blobs, and dynamic colors.
  - `vaporwave`: Windows 95 aesthetic, mallsoft sunsets, and grid typography.
  - `80s-digital`: Red LED segments and glowing displays.
  - `cyberpunk`: Brutalist UI, warning tape, and neon lights.
  - `terminal`: Pure green-on-black monospace matrix vibe.
- **Micro-interactions**: Seamless overlay animations when switching between themes.
- **Lightweight stack**: Vanilla UI powered by Vite and TypeScript, with no heavy frontend frameworks.

## Getting Started

First, make sure you have [Bun](https://bun.sh/) installed (or you can use `npm`/`yarn`/`pnpm`).

### Installation

Clone the repository and install dependencies:

```bash
bun install
```

### Development

Run the development server locally:

```bash
bun run dev
```

### Building for Production

Compile and minify for production:

```bash
bun run build
```

The optimized output will be available in the `dist` directory, ready to be deployed to any static host like Netlify, Vercel, or GitHub Pages.
